# Connect your Soclo account

Remote Streamable HTTP endpoint: https://mcp.soclo.app/mcp/auth

Let the host discover OAuth from the server challenge and complete sign-in in your browser. No static token, password or Authorization header is included in this package. Review the permissions on the Soclo approval screen.

You can revoke access at https://mcp.soclo.app/connections. Never paste credentials into a conversation or a skill file.
