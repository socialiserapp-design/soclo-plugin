# Soclo batch-from-photo

Read the current /batch-from-photo playbook and references/soclo-workflow.md first. Discover the Library with soclo_library_search; let the owner select the exact saved photo and retain its ID and updated_at version. Do not pick a different asset or treat an arbitrary remote URL as reviewed evidence. Confirm the current source-readiness and rights requirements.

Read the brand and wallet. Prepare with soclo_host_plan_prepare using selectedInput, read the complete returned guides and author several distinct storyboards. Reuse the exact selected source ID in each applicable scene.referenceIds, preserve the owner's Brand Kit visual choice and import each project with soclo_host_plan_import_selected and the exact version and guide identities.

Use soclo_video_variants_quote, display every per-item full render price and any total, then wait. Approve only items and ceilings the owner actually chose, one exact item per soclo_video_variants_approve call. Recover each original generation after interruptions and return its actual saved result. No batch setting grants spending, publishing or Autopilot authority.
