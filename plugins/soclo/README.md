# Soclo for Claude

Plan, make and publish on-brand marketing with your Soclo Brand Kit and library.

## Connect

In Claude, open Settings → Connectors → Add custom connector. Paste `https://mcp.soclo.app/mcp/auth` and complete Soclo sign-in. For Claude Code, install this folder as a local plugin, or add it to your plugin marketplace. The `.claude-plugin/plugin.json` manifest loads all seven skills and the MCP connection.

Server: `https://mcp.soclo.app/mcp/auth`. Sign in with your own Soclo account; no token is included.

All seven skills include their referenced workflow. Read `AUTHENTICATION.md` for permissions. Generated media needs an accepted quote. Publishing and ad spending need their own approval.
